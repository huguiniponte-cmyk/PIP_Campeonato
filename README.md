# PIP_Campeonato
Projeto PIP - Sistema de Gestão de Campeonatos de Futebol. Grupo: Hugo, Anaisa, Pablo.

Eu já criei a estrutura de pastas que o professor (e o enunciado) exigem para um projeto C profissional.

Esta organização é fundamental para não misturarmos tudo:

/src (Source): É aqui que vamos guardar os nossos ficheiros de código principais (os ficheiros .c que contêm a lógica).

/include (Headers): É aqui que guardamos os "cabeçalhos" (os ficheiros .h que definem as nossas funções e estruturas).

/data: É a pasta onde o nosso programa vai guardar e ler os ficheiros de texto (ex: equipas.txt, jogos.txt).

/docs: (Para já está vazia) É onde podemos guardar documentação extra, como diagramas de fluxo, etc.

Makefile: Este é o ficheiro que o professor vai usar para compilar o nosso projeto. O Pablo também o vai usar para compilar tudo automaticamente, em vez de o fazer à mão.

README.md: É a "página de rosto" do nosso projeto.
